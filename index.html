TABIND Scrabble Project

Alphabetized output for the rack `tabind`, with each letter used at most once. The Python solver reads a full NWL2023 Scrabble dictionary file, then filters it to the whole playable words that can be made from those six characters.

    Run the Program

    The project includes a full NWL2023 dictionary file at data/scrabble_dictionary.txt, one valid word per line. Run:

    python src/tabind_solver.py
    uv run python src/tabind_solver.py

    Or pass the full dictionary path explicitly:

    python src/tabind_solver.py path/to/scrabble_dictionary.txt

    Sources

    The solver reads from the bundled NWL2023 Scrabble word list in data/scrabble_dictionary.txt. The source dictionary file includes definitions, so this project keeps only the first token on each line as the playable word. You can replace it with a different full dictionary file if your class requires a specific edition.
